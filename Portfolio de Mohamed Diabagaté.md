## 🔧 Modifications possibles

Pour personnaliser le portfolio :

1. **Informations personnelles** : Modifier les textes dans `index.html`
2. **Couleurs** : Ajuster les variables CSS dans `:root` (styles.css)
3. **Projets** : Ajouter/modifier les cartes de projets
4. **Images** : Remplacer les images dans le dossier `assets/`
5. **Contact** : Mettre à jour les informations de contact
